# Google Play release preparation

No release is authorized or scheduled. This is an **experimental**, independent open-source app.

## Before first release

- Build a signed Android App Bundle (AAB), with signing keys stored privately.
- Confirm package name, application ID, icons, screenshots and multilingual descriptions.
- Verify SIWC login, account switching, logout, model availability, error states and user-specific usage limits on physical Android hardware.
- Follow Google's current target API, Play Console testing, app content, data-safety and account deletion requirements as applicable at submission time.
- Publish a clear privacy policy describing identity data, locally stored tokens and game answers transmitted to OpenAI to enable each request.
- Provide in-app privacy and connection management; avoid recording tokens or questions in analytics logs.
- Ensure store page clearly states: independent experimental app; not affiliated with OpenAI; supported plan required for SIWC-powered inference.
- Review OpenAI branding, SIWC license, usage terms, and available access plans before publication.
- Test accessibility, RTL scripts, long languages, orientation and network interruption.
- Start with Play internal testing, review user reports, then consider a production release.
- Do not publish, configure billing, or spend money without explicit owner instruction.

## Intended listing short description

Experimental multilingual Twenty Questions game for Android, powered by AI.
